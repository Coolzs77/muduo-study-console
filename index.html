CppAIService Linux + CMake 企业级开发指引

1. 代码位于本地仓库： e:/workspace/CppAIService。

2. 依赖安装： 包含 muduo, OpenSSL, CURL, MySQL Client, RabbitMQ, OpenCV 与 ONNX Runtime。

3. 编译命令： mkdir -p build && cd build && cmake .. && make -j4。

4. 服务启动： ./http_server -p 80，在浏览器访问 http://localhost/entry。
