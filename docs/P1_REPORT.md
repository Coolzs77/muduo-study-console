## 三、Yuque Knowledge Explorer 功能设计与实现

### 1. 交互与布局架构 (Two-Column Responsive Layout)
- **专栏导航栏目 (`#nav-knowledge`)**: 位于顶部主导航，与「攻坚大盘与架构拓扑」并列，支持单键快捷键 `7` 或 `k`/`K` 毫秒级秒切。
- **左侧目录控制台 (4 cols)**:
  - **最近阅读小药丸 (`yq-recent-pills`)**: 自动去重记录最近浏览的 4 篇文章，快速往返切换。
  - **标签过滤条**: 支持按 `全部`、`架构设计`、`设计模式`、`协议解析`、`核心组件`、`高级特性`、`收藏`、`待攻坚` 一键筛查。
  - **全文与元数据模糊搜索**: 响应输入，实时过滤文章标题、分类、关联类、源码文件及考点。
  - **专栏目录卡片列表 (`yq-directory-list`)**: 显示每篇文章的序号、字数、分类标签及当前掌握度徽章。
- **右侧沉浸阅读器 (8 cols)**:
  - **元数据与原文直达 (`yq-reader-meta`)**: 显示章节分类、准确字数、更新日期与“100% FULL 离线就绪”状态。
  - **6 阶掌握度评定器 (`yq-mastery-selector`)**:
    - `L0 未学习` ➔ `L1 了解` ➔ `L2 理解` ➔ `L3 能够解释` ➔ `L4 能够编码` ➔ `L5 能够应用`
    - 单击即时触发本地持久化，并在顶部统计大盘实时同步更新。
  - **源码行级与工程调用链路锚定卡片 (`yq-source-trace-card`)**:
    - 动态展示文章对应的 `CppAIService` 真实源码文件（如 `src/http/HttpRequest.cpp`）、核心类（如 `HttpRequest`）、关键调用函数。
    - 列出该章节对应的**大厂面试深挖考点**。
    - 提供「生成攻坚任务」与「记录排错」快捷入口。
  - **安全 Markdown 正文渲染器 (`yq-reader-scroll` / `yq-reader-body`)**:
    - 自研轻量级防弹渲染器：对代码块与行内代码进行精准保护，对 HTML 字符进行安全转义彻底防范 XSS 漏洞。
    - 完美适配 C++ 代码高亮、GFM 规范表格、图文混合排版与引用块警示卡。

### 2. 数据模型与全盘持久化联动
知识库的所有用户行为均与整站的状态管理系统实现无缝打通：
1. **独立本地存储键**:
   - `cppai_knowledge_mastery`: `{ [artId]: 0..5 }`
   - `cppai_knowledge_favs`: `[ artId, ... ]`
   - `cppai_knowledge_recent`: `[ artId, ... ]`
2. **全局备份与导入兼容**:
   - 导出 `muduo_v5_study_backup_*.json` 时，自动打包专栏知识掌握度、收藏列表与最近阅读。
   - 导入数据时，支持智能「合并（保留更高掌握等级）」与「覆盖」双策略。
   - 点击「重置系统」时，安全清空两套体系的状态，保持数据纯净一致。
